# marenu-web

Sitio web de MARENÚ (Next.js App Router, React, TypeScript, CSS).

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
npm start
```

Los archivos oficiales de marca (logotipo, sello) deben colocarse en `public/brand/`; las fotografías en `public/images/`.
