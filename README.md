# MarenuMaster

Repositorio único de MARENÚ. Ver [MARENU_MASTER_DEFINITION.md](MARENU_MASTER_DEFINITION.md).

- `marenu-web/`: sitio web (Next.js + React + TypeScript).
- `marenu-core/`: backend (futuro).

## Ejecutar la web

```bash
cd marenu-web
npm install
npm run dev
```

Abrir http://localhost:3000. Otros comandos: `npm run lint`, `npm run build`, `npm start`.
